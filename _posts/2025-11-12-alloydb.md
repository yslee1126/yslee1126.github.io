### 개요 
- 스프링 부트환경에서 GCP AlloyDB 로 데이터베이스 연결하는 경우 설정 방법  
- 연결정보는 시크릿 매니저를 사용 

### 설정 

- 로컬 개발 환경인 경우 

- 구글 계정 로그인
- 내 계정에 개발 DB 접근 권한 부여되어 있어야함 
```bash
gcloud auth application-default login
```

- 의존성 설정 

```groovy
runtimeOnly 'org.postgresql:postgresql:42.7.7'
// 특정 프로필에서만 사용하도록 하고 싶은 경우 devRuntimeOnly.extendsFrom runtimeOnly 이런식으로 확장 설정을 해서 특정 프로파일에서만 로딩 
devRuntimeOnly 'com.google.cloud:alloydb-jdbc-connector:1.2.6'

implementation 'com.google.cloud:spring-cloud-gcp-starter-secretmanager'
```

- yml 설정파일 설정 

```yaml
spring:
  cloud:
    gcp:
      project-id: 프로젝트아이디
      secretmanager:
        enabled: true
      secret:
        name: 시크릿이름 

# 로컬에서 datasource 설정은 동일한데 서버에서는 아래 설정으로 
  datasource:
    hikari:
      data-source-properties:
        # 기본 TCP 말고 alloy db 용 보안 소켓 연결 (IAM 인증 등 과정이 포함됨)
        socketFactory: com.google.cloud.alloydb.SocketFactory
        # PSC (private service connection), PRIVATE ( 클러스터 프라이빗 IP 사용), PUBLIC ( 퍼플릭 IP 사용) 
        alloydbIpType: PSC
        # DB password 말고 IAM 토큰 사용 여부 
        alloydbEnableIAMAuth: true
        alloydbInstanceName: ${db_instance}
      # alloy db 소켓 방식이므로 host, port 정보가 필요없음   
      jdbc-url: jdbc:postgresql:///${db_name}

```


- 시크릿 매니저 로딩하는 부분 

```java

@Autowired
private SecretManagerTemplate secretManagerTemplate;

@PostConstruct
public void loadSecrets() {
  String json = secretManagerTemplate.getSecretString(secretName);
  ObjectMapper mapper = new ObjectMapper();
  JsonNode node = mapper.readTree(json);
  
  // instance uri 는 projects/프로젝트ID/locations/리전/ clusters/클러스터ID/instances/인스턴스ID 이런 형태 
  String dbInstance = node.get("ALLOYDB_INSTANCE_URI").asText();
  
  // 유저는 적절한 권한이 있는 서비스 계정 ID 
  String dbUser = node.get("DB_USER").asText();

  secrets.put("db_user", dbUser);
  secrets.put("db_instance", dbInstance);

  environment.getPropertySources().addFirst(new MapPropertySource("gcp-secrets", secrets));
}

```

- 로컬 환경인 경우 db 접속 설정은 이전과 동일 

```yaml
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://${db_host}:${db_port}/${db_name}
    username: ${db_user}
    password: ${db_password}
```


- user 계정과 password 는 내가 로그인한 구글 정보를 가져와서 설정해야 한다 

```java
private String getAccessToken() throws IOException {
  
  // 토큰이 없거나 처음 요청시에만 새로 생성하여 비번에 입력 
  if (cachedCredentials == null) {
    cachedCredentials = GoogleCredentials.getApplicationDefault()
      .createScoped(Collections.singletonList("https://www.googleapis.com/auth/sqlservice.login"));
    cachedCredentials.refreshIfExpired();
  }
  
  return cachedCredentials.getAccessToken().getTokenValue();
  
}

private String getUserEmailFromToken() {
  if (cachedCredentials == null) {
    cachedCredentials = GoogleCredentials.getApplicationDefault()
      .createScoped(Collections.singletonList("https://www.googleapis.com/auth/userinfo.email"));
    cachedCredentials.refreshIfExpired();
  }
  
  String accessToken = cachedCredentials.getAccessToken().getTokenValue();

  HttpClient client = HttpClient.newHttpClient();
  HttpRequest request = HttpRequest.newBuilder()
    .uri(java.net.URI.create("https://www.googleapis.com/oauth2/v2/userinfo"))
    .header("Authorization", "Bearer " + accessToken)
    .GET()
    .build();

  HttpResponse<String> response = client.send(request,
    HttpResponse.BodyHandlers.ofString());

  ObjectMapper mapper = new ObjectMapper();
  JsonNode userInfo = mapper.readTree(response.body());
  return userInfo.get("email").asText();
  
}
```
